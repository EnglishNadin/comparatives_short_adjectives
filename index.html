Adjective type Rule Examples
Most short adjectives + -er / -est slow → slower → the slowest
Ending in -e + -r / -st nice → nicer → the nicest
Ending in consonant + y y → i + -er / -est funny → funnier → the funniest
Ending in one vowel + one consonant double consonant + -er / -est big → bigger → the biggest

Remember: We use than with comparatives and the with superlatives.

Exercise 2 of 4. Complete with the comparative form.

5. Today is (hot) than yesterday.
